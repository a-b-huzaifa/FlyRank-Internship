### How to Run Assignments

Each assignment is self-contained in its respective folder and includes its own detailed `README.md` with installation and execution commands. 

To run **Assignment 1**:
1. Open your terminal in the [Assignment 1](./Assignment%201) folder.
2. Install dependencies: `npm install`
3. Start the server: `npm start`
4. Access the API at `http://localhost:3000` or interactive docs at `http://localhost:3000/docs`.
